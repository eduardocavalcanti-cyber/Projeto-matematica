# Calculadora de Álgebra Linear (PHP 8.4 + PHPUnit)

Aplicação web e suíte de testes automatizados desenvolvida em PHP para operações com matrizes e resolução de sistemas lineares via Eliminação de Gauss.

## Tecnologias e Ferramentas
- PHP >= 8.4
- Composer
- Laravel Herd
- PHPUnit 11
- Bootstrap 5

## Algoritmos Implementados
1. **Soma de Matrizes:** Adição elemento a elemento para matrizes de mesma dimensão.
2. **Multiplicação de Matrizes:** Produto matricial ($A_{m \times n} \times B_{n \times p}$).
3. **Transposição de Matrizes:** Inversão de linhas por colunas.
4. **Determinante (Recursivo):** Cálculo de determinante via expansão por cofatores (Laplace) para matrizes $N \times N$.
5. **Sistemas Lineares ($Ax = B$):** Resolução via **Eliminação de Gauss com Pivotamento Parcial** e substituição regressiva.
