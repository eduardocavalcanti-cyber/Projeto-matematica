# Calculadora de Álgebra Linear (PHP 8.4 + PHPUnit)

Aplicação web e suíte de testes automatizados para operações matriciais e resolução de sistemas lineares.

## Requisitos e Ferramentas
- PHP >= 8.4
- Composer
- Laravel Herd
- PHPUnit 11
